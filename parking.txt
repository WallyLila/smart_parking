Build a modern, sleek and premium **Smart Parking IoT Dashboard** web application.

The application is a frontend prototype for a real IoT smart parking system with **2 parking slots**.

## Tech Stack

Use:

* React
* Vite
* Tailwind CSS
* Lucide React for icons
* JavaScript or JSX
* Component-based architecture

Do NOT use React Native.

For this first version, build the frontend only.

Do NOT connect to ESP32, Supabase, MQTT, APIs, or any backend yet.

Use realistic mock data and simulated device states so the UI feels like a real IoT dashboard.

The code structure should make it easy to replace mock data with real Supabase/ESP32 data later.

---

# Main Design Direction

The visual style should be inspired by premium modern Smart Home / IoT dashboards.

The final UI should feel:

* Premium
* Minimal
* Modern
* Clean
* Professional
* Slightly futuristic
* Mobile-first
* Suitable for an IoT university project

Use a **Dark Mode** interface.

Background:

* #121212
* Tailwind `bg-neutral-950` / `bg-neutral-900`

# STATE MANAGEMENT

Use React state for UI interactions.

The following should work:

* switch between Dashboard / Usage / Account
* toggle parking light
* toggle settings
* switch analytics time range
* interact with navigation
* simulate changing slot status if useful

# FUTURE BACKEND COMPATIBILITY

Structure the application so that the mock data can later be replaced by:

ESP32
↓
HC-SR04
↓
WiFi
↓
Supabase
↓
React Dashboard

Do not implement this connection yet.

But make component props/data structures clean enough that replacing mock data with Supabase realtime data later is straightforward.

For example:

<ParkingSlotCard
slot={slot}
/>

rather than hard-coding:

<ParkingSlotCard
distance="185"
status="available"
/>
